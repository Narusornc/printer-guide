Step 01

เปิดหน้าต่าง Run เพื่อเข้าถึง Print Server Open Run Dialog to Access Print Server

  1. กดปุ่มคีย์ลัด Windows + R บนคีย์บอร์ดเพื่อเปิดหน้าต่าง Run
  2. พิมพ์ที่อยู่เครือข่าย \\10.204.24.244 แล้วคลิก OK
  1. Press the shortcut key Windows + R on your keyboard to open the Run dialog.
  2. Type network address \\10.204.24.244 and click OK.
\\10.204.24.244
Step 02

ยืนยันตัวตนด้วยบัญชี VISTEC Account Authenticate with VISTEC Credentials

  1. ในช่อง User name: กรอกชื่อผู้ใช้ตามด้วยโดเมน เช่น vistec\yourname.s (ต้องมี vistec\ นำหน้าเสมอ)
  2. ในช่อง Password: กรอกรหัสผ่านบัญชี VISTEC
  3. ทำเครื่องหมายถูกที่ช่อง Remember my credentials เพื่อบันทึกการเข้าสู่ระบบ
  4. คลิกปุ่ม OK
  1. In User name: Enter username with domain prefix, e.g., vistec\yourname.s (always prefix with vistec\).
  2. In Password: Enter your VISTEC account password.
  3. Check the box Remember my credentials to save credentials.
  4. Click OK.
Step 03

เชื่อมต่อเครื่องพิมพ์ Follow-you-print Connect to Follow-you-print Queue

  1. เมื่อหน้าต่างโฟลเดอร์เซิร์ฟเวอร์เปิดขึ้นมา ให้ค้นหาไอคอนเครื่องพิมพ์ Follow-you-print
  2. คลิกขวาที่ Follow-you-print แล้วเลือกเมนู Connect...
  3. ระบบ Windows จะทำการดาวน์โหลดและลงทะเบียนไดรเวอร์โดยอัตโนมัติ
  1. In the opened server folder window, locate Follow-you-print printer icon.
  2. Right-click on Follow-you-print and choose Connect...
  3. Windows will automatically download and register the driver.
การสั่งพิมพ์งาน: เลือกเครื่องพิมพ์ชื่อ Follow-you-print on 10.204.24.244 เมื่อส่งงานพิมพ์แล้ว สามารถไปแตะบัตรเพื่อสั่งปล่อยเอกสารที่เครื่องพิมพ์ Xerox ได้ทุกจุดในอาคาร Printing: Select printer Follow-you-print on 10.204.24.244. After sending your print job, simply tap your ID card at any Xerox multifunction printer across campus to release your documents.
Step 01

เปิดหน้าต่าง Connect to Server Open Connect to Server

  1. เปิด Finder (ไอคอนหน้ายิ้มบน Dock) หรือคลิกขวาที่ไอคอน Finder แล้วเลือก Connect to Server...
  2. หรือที่แถบเมนูด้านบนให้คลิก Go > Connect to Server... (คีย์ลัด Command + K)
  3. ในช่อง Server Address พิมพ์ smb://10.204.24.244 แล้วคลิก Connect
  1. Open Finder (smiley-face icon on the Dock), or right-click the Finder icon and choose Connect to Server....
  2. Alternatively, in the top menu bar click Go > Connect to Server... (shortcut Command + K).
  3. In the Server Address field type smb://10.204.24.244 and click Connect.
smb://10.204.24.244
Step 02

ยืนยันตัวตนและเลือกโฟลเดอร์ Driver MAC Authenticate and Mount Driver MAC

  1. เมื่อมีหน้าต่างยืนยัน You are attempting to connect to the server ให้คลิก Connect
  2. เลือก Registered User กรอก Username และ Password บัญชี VISTEC (ตัวอย่าง user.n)
  3. ติ๊ก Remember this password in my keychain แล้วคลิก Connect
  4. ที่หน้าต่างเลือก Volume ให้เลือก Driver MAC แล้วคลิก OK
  1. When the You are attempting to connect to the server confirmation appears, click Connect.
  2. Select Registered User and enter your VISTEC Username and Password (e.g. user.n).
  3. Check Remember this password in my keychain and click Connect.
  4. In the volume selection window choose Driver MAC and click OK.
Step 03

เปิดไฟล์ติดตั้ง Driver Locate the Driver Installer

  1. หน้าต่าง Finder ของ Driver MAC จะเปิดขึ้น แนะนำให้เลือกโฟลเดอร์ Mac OS 26.0 above ถึงแม้จะเป็นรุ่นที่เก่ากว่า หากลงแล้วติดปัญหาค่อยลง Version เก่า
  2. เปิดโฟลเดอร์นั้น จะพบไฟล์ .dmg ดับเบิลคลิกเพื่อเปิด
  3. ดับเบิลคลิกไฟล์ติดตั้ง .pkg (FUJIFILM Print Driver for Mac OS X Installer) เพื่อเริ่มติดตั้ง
  1. The Driver MAC Finder window opens. It is recommended to choose Mac OS 26.0 above even on older macOS versions; install older driver versions only if you encounter issues.
  2. Open that folder and double-click the .dmg file to mount it.
  3. Double-click the .pkg installer (FUJIFILM Print Driver for Mac OS X Installer) to start installing.
Step 04

ติดตั้ง Driver เครื่องพิมพ์ Run the Driver Installer

  1. หน้า Introduction คลิก Continue
  2. หน้า License คลิก Continue แล้วคลิก Agree เพื่อยอมรับข้อตกลง
  3. หน้า Installation Type คลิก Install
  4. กรอกรหัสผ่านเครื่อง Mac (Username/Password ของผู้ดูแลเครื่อง) แล้วคลิก Install Software
  5. เมื่อขึ้น The installation was successful คลิก Close
  1. On the Introduction page click Continue.
  2. On the License page click Continue, then Agree to accept the terms.
  3. On the Installation Type page click Install.
  4. Enter your Mac administrator Username/Password and click Install Software.
  5. When The installation was successful appears, click Close.
Step 05

เปิดหน้า Add Printer และเพิ่มแท็บ Advanced Open Add Printer and Enable Advanced Tab

  1. ไปที่ System Settings (หรือ System Preferences) > Printers & Scanners
  2. คลิกปุ่ม + (Add Printer, Scanner, or Fax...)
  3. หากยังไม่มีไอคอน Advanced บนแถบเครื่องมือ: คลิกขวาที่แถบเครื่องมือ เลือก Customize Toolbar...
  4. ลากไอคอน Advanced (รูปเฟืองคู่) ไปวางบนแถบเครื่องมือ แล้วคลิก Done
  1. Go to System Settings (or System Preferences) > Printers & Scanners.
  2. Click the + button (Add Printer, Scanner, or Fax...).
  3. If the Advanced icon is not in the toolbar: right-click the toolbar and choose Customize Toolbar....
  4. Drag the Advanced icon (double gear) onto the toolbar, then click Done.
Step 06

กรอกข้อมูลในแท็บ Advanced Fill In the Advanced Tab

  1. คลิกแท็บ Advanced ที่ช่อง Type: เลือก Windows printer via spoolss
  2. ช่อง Device: เลือก Another Device
  3. ช่อง URL: วางที่อยู่ตามกล่องด้านล่าง
  4. ช่อง Name: พิมพ์ VISTEC Printer (หรือชื่อที่ต้องการ)
  1. Click the Advanced tab. Set Type: to Windows printer via spoolss.
  2. Set Device: to Another Device.
  3. In URL: paste the address from the box below.
  4. In Name: type VISTEC Printer (or any name you prefer).
smb://10.204.24.244/Follow-you-print?encryption=no
ข้อกำหนดสำคัญ: ส่วนท้าย URL ต้องระบุพารามิเตอร์ ?encryption=no เสมอ เพื่อป้องกันปัญหาค้างสถานะ Hold for Authentication Critical Requirement: The URL must end with ?encryption=no to prevent the print queue from getting stuck on "Hold for Authentication".
Step 07

เลือก Driver และเพิ่มเครื่องพิมพ์ Select the Driver and Add the Printer

  1. ในหน้าต่าง Printer Software พิมพ์ค้นหา 3371
  2. เลือก FF K529t for ApeosPort-VI C3371 PS แล้วคลิก OK
  3. ตรวจสอบว่าช่อง Use แสดงชื่อไดรเวอร์ที่เลือก แล้วคลิก Add
  4. หากมีหน้าต่างตั้งค่า Options (เช่น Paper Tray Configuration) ให้ตรวจสอบค่าแล้วคลิก OK
  1. In the Printer Software window search for 3371.
  2. Select FF K529t for ApeosPort-VI C3371 PS and click OK.
  3. Confirm the Use field shows the chosen driver, then click Add.
  4. If an Options window appears (e.g. Paper Tray Configuration), review the values and click OK.
Step 08

ตรวจสอบและทดสอบการสั่งพิมพ์ Verify and Test Printing

  1. กลับไปที่ Printers & Scanners จะเห็น VISTEC Printer สถานะ Idle
  2. ทดลองสั่งพิมพ์เอกสารจากโปรแกรมใดก็ได้ โดยเลือกเครื่องพิมพ์ VISTEC Printer (หรือชื่อที่ตั้งเอาไว้)
  3. หากมีกล่องถามรหัสผ่าน ให้กรอก Username และ Password บัญชี VISTEC
  4. เมื่อสถานะในคิวการพิมพ์ส่งสำเร็จ สามารถเดินไปที่เครื่องปริ้นเพื่อสั่งพิมพ์จริงได้ทันที
  1. Return to Printers & Scanners; VISTEC Printer is listed with status Idle.
  2. Print a test document from any application, selecting VISTEC Printer (or the name you specified).
  3. If prompted for credentials, enter your VISTEC username and password.
  4. Once the print queue reports completion, you can proceed directly to the physical printer to release your print job.
Step 01

แตะบัตรประจำตัวที่ตัวอ่าน (Card Reader) Tap ID Card at the Card Reader

  1. นำบัตรประจำตัวพนักงาน หรือ บัตรนักศึกษา แตะที่กล่อง Card Reader สีขาวด้านขวาของเครื่อง ถ้าไม่ได้จะขึ้น login failed ให้ทำตามขั้นตอนต่อไป
  2. กดปุ่ม Log In / Out บนแผงปุ่มกด 1 ครั้ง เพื่อเข้าสู่หน้าจอลงทะเบียนผู้ใช้
  1. Tap your employee or student ID card onto the white Card Reader located on the right side of the machine. If unlinked, the screen will indicate login failed; proceed to the next step.
  2. Press the Log In / Out button on the physical keypad once to enter the user registration screen.
Step 02

กรอก Username และ Password เพื่อผูกบัตร Enter Credentials and Bind Card

  1. ให้กรอก Username บัญชี VISTEC แล้วกดปุ่ม Next
  2. กรอก Password ให้ถูกต้อง แล้วกดปุ่ม Enter
  3. หลังจากที่ Login แล้วจะขึ้น Menu (ดังรูปที่ 3.4) หลังจากนั้นให้ลองแตะบัตรอีกครั้ง ถ้าได้จะขึ้น User Details validated. (ดังรูปที่ 3.5) แต่ถ้าไม่ได้จะขึ้น failed ต้องทำการ login ใหม่เพื่อลองอีกครั้ง
  1. Enter your VISTEC Username and tap Next.
  2. Enter your Password accurately and press Enter.
  3. After logging in, the Main Services Menu will appear (Figure 3.4). Then, tap your card again. If successful, the screen will display User Details validated. (Figure 3.5). If it shows failed, please log in again to retry.
